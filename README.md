# Web-Based Guidance and Counseling Information System

A web-based Guidance and Counseling Information System developed as a final-year project to support the recording, monitoring, and evaluation of student counseling cases.

## About the Project

This system was developed to help Guidance Counselors manage student counseling information digitally. It supports the process of recording cases, counseling activities, student development monitoring, and evaluation.

The system provides different access levels for:
- **Admin** – manages users and system data.
- **Guidance Counselor** – records counseling cases, counseling activities, monitoring, and evaluation.
- **Parent** – views relevant student counseling and development information.

## Main Features

- User authentication and role-based access control
- Student data management
- Counseling case reporting
- Counseling and mentoring records
- Student development monitoring
- Evaluation of counseling cases
- Counseling schedule management
- Counseling result records
- Dashboard and reporting
